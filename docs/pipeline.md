# Pipeline and acceptance

Primary command: `python -m vehiclerecon run projects/tesla`. `inspect` validates
metadata; `init` creates a draft; `review` records an explicitly supplied visual
decision. `run --until <stage-id>` stops at a migration boundary. `--no-cache`
forces reconstruction. Set the Blender/browser environment variables if needed.

| Stage ID | Required result |
| --- | --- |
| preflight | Valid schemas/data/references, profile floors, calibration coherence and available runtime. |
| references | Input identities and actual decoded image dimensions. |
| calibration | Fresh metric scene, four packed planes, five cameras, common datums and aligned proof renders. |
| overlay | Raw HSV/component evidence; no claim of semantic understanding. |
| cage | Resolved world-space curves, symmetry and explicit guide structure. |
| surfaces | Boundary-controlled quad/SubD graph, final cowl/bridge/A-foot and real arches. |
| silhouette | Actual fixed-camera masks; required thresholds and baseline-regression allowance. |
| details | Parameterized components, real cavities, separate panels/glass and centered wheel roots. |
| geometry | Explicit cleanup followed by a non-mutating geometry/role/pivot audit. |
| presentation | Real-topology wires, studio/orthographic/diagnostic images, final silhouette rerun and current explicit visual review. |
| export | Current audit, masks, review and input hashes; direct Blender GLB. |
| glb_verify | Node identities, finite positions/normals, index integrity, triangles and bounds against evaluated Blender. |
| viewer | Exact GLB embedding and real desktop/mobile WebGL/control tests. |
| delivery | Fresh source/export/review bindings and a project-scoped artifact manifest. |

Every stage reports PASS, FAIL, SKIP or BLOCKED. Required FAIL/BLOCKED returns a
nonzero exit and blocks dependents. SKIP means previously successful outputs
were found and their hashes verified; it does not skip acceptance policy.
Production gates raise explicit errors rather than assertions.

Tesla floors: SIDE .94, TOP .92, FRONT .92, REAR .90. Frozen evidence is
.957230/.936083/.931202/.944724. The pre-migration project policy permits at most
.002 absolute IoU regression; the delivered reconstruction also compares to the
better frozen values. Geometry, structure, wheel positions and visual surfaces
must remain equivalent. A passing outer silhouette alone is insufficient.

The first silhouette gate precedes details; the final gate runs against the
saved presentation blend after all visible components. Export rejects a mask
report from another blend or model-input state. Curve conversion happens only
in memory; the editable source blend is retained.

If visual review is absent or stale, stage 10 is BLOCKED. Inspect all listed
proofs and run `review --reviewer ... --decision PASS|FAIL --note ...` explicitly.
No reviewer decision is generated by `run`. Existing illustrative-source and
scale limitations must remain documented. Geometry/proof/config changes revoke
the old review. Merely running a script cannot certify visual surface quality.

Cache entries under `.cache/` contain scoped inputs, implementation identity,
dependency result keys, status and output hashes. A missing/corrupt output
invalidates its entry. Dependency result keys include output identities to keep
Blender checkpoint/mask hashes coherent. Runtime version evidence is captured.
Calibration/cage changes invalidate dependent geometry; lights-only component
changes preserve surfaces; viewer-label changes rebuild viewer/delivery only.
Presentation asset caching supports resuming an explicit review without
regenerating the reviewed images. No semantic key contains a timestamp.

PNG text metadata is removed after rendering, retaining pixel and color-profile
chunks. Full command/version/exit/log provenance is kept under
validation/execution instead. Browser QA owns an isolated localhost profile and
closes that browser; it never attaches to the user's browser session.

FBX is unavailable in v0.1 and raises BLOCKED if requested through its API. The
framework does not claim Cyberpunk import readiness or unimplemented formats.
